# 每日 EFC 额度调整：已确认边界

用户已确认每日最多 2 次 EFC，替代原年度额度，未用额度不跨日结转。此项是项目情景假设，不是西班牙市场规则。主线程为完成本次跨模块实现和验收，批准修改本仓库的 code、reports 及新增 output 运行目录；原始 input 数据只读。

## 场景及周期

- 正式统计期：Europe/Madrid 当地 2026-01-01 00:00 至 2026-09-01 00:00（结束时刻不含），共 243 个自然日。
- 原100 MW充电／100 MW放电，aFRR上／下调申报上限各100 MW；50／100 MW，申报上限各100 MW；50／100 MW，申报上限各150 MW理论敏感性。
- 三场景总容量200 MWh，SOC能量边界10–190 MWh（5%–95%）；期初与正式期末均为10 MWh，充／放效率各92%。进口／出口功率与各场景充／放功率相同。
- 保留容量收入代理系数进入目标函数重新优化。仅容量收入折减；激活和物理承诺沿用既有假设。仍为两天规划、一天执行的事后条件测算，不是全年联合最优，也不是事前可执行收益。
- 2026年独立起算，不继承2025年SOC或已冻结订单；开头已关闭交易沿用现有零初始承诺规则。
- 2026-09-01 是现有算法需要的前瞻日，不计入正式收益、EFC或243日统计；8月31日期末SOC仍单独约束。前瞻数据缺失按原策略处理。

## 数学约束及验收

对每个马德里自然日 d，包括规划窗口内尚未执行的第二天：

`sum[(0.92 × P_charge + P_discharge / 0.92) × duration_hours] / 360 MWh <= 2 EFC`。

求和覆盖该日所有基准和激活物理子时段；充放功率单位MW，持续时间单位小时。等价于每日电池侧充放吞吐量合计不超过720 MWh。每日最多2次，不强制用满，不跨日借用或累计。23/25小时夏令时日仍为2次；部分缺失日也不按有效小时缩减2次上限，缺失时段沿用零功率、SOC衔接、收益空值处理。

删除当前情景中的年度额度约束及年度终端EFC预留。为兼容旧输入文件，solver_input.json保留原annual_efc_budget字段，manifest明确标注其为不生效的历史元数据；新结果annual_budget为null，cycle_policy记录daily_only，annual_used仅为年度内累计使用统计。243天的逐日上限合计486次是自然推导上界，不是另一个可跨日调配的额度池。

验收须覆盖：每日建模上限、独立物理功率重构EFC、逐日执行和全期统计一致、不同本地日期不共用额度、夏令时、旧年度零额度不阻止daily_only运行、恢复计算锁定日额度配置、初末SOC、全部243日完成、收益汇总及输入可比性。

## 数值恢复记录

100／100 MW场景初次运行在2026-04-21出现HiGHS不可行，presolve重试亦未恢复。重构前一窗口对该日的计划，EFC为1.8260912864次，SOC最低约9.9999999416 MWh，显示冻结边界存在微小数值误差。诊断分别尝试1e-9、1e-7及1e-5可行性容差；1e-5成功，并通过原有1e-5独立约束、现金和执行审计。该值没有提高独立验收阈值。

恢复程序新增显式可选的 `--numerical-retry-tolerance`，最大只允许1e-5；仅在普通及presolve重试仍报告不可行时使用。保持原模型约束、冻结订单、目标和MIP gap不变，每次重试单独存档。原失败目录保留，恢复结果写入独立目录；最终报告须合并验证恢复前后的全部243日，并记载来源链及重试记录。
