# 西班牙独立储能：交易策略与建模假设清单

版本：v1.3；独立最终审核PASS（P0=0、P1=0、P2=0），主线程验收通过；编制：主线程；日期：2026-09-16。审核记录见 [独立审核记录](review_ES_MODEL_DESIGN_2026-09-16.md)。

## 1. 要解决的交易问题

模型为价格接受者的研究工具，决定电池在日前买卖多少电、在日内如何调整已经成交的头寸，以及为 aFRR 上下调保留多少功率与能量。首版把“报了多少”“成交多少”“激活多少”“实际充放多少”分开。

日前、日内拍卖、连续日内和 aFRR 容量及能量均在范围内。不平衡仅核算非主动交付误差；mFRR、RR、FCR、SRAD 不进入收益。定价机组识别不构成本模型依赖。

策略是：先衡量跨时段电能价值，再比较提供备用所占用的功率、能量和未来交易机会；每次收到新的已发布信息后更新未关闭的决策，已成交义务和已中标容量保持固定。没有预设“中午必充、晚间必放”或“容量价格高就一定提供备用”。

## 2. 决策顺序与信息

实际先后由带日期版本的事件表决定，不把下表行顺序硬编码为市场时间顺序。容量采购与日内事件应按官方日程合并排序。

| 决策事件 | 此时可以使用 | 可以决定 | 必须锁定 |
|---|---|---|---|
| 日前报价 | 当时预测价格、负荷/天气预测、当前 SOC、已公告限值 | 各日前合同买卖报价量 | 历史成交与设备状态 |
| aFRR 容量报价 | 当时已发布的市场结果、容量需求及容量价格预测、激活预测 | 上下调容量申报量，可不对称 | 已成交电能义务；不得默认日前或容量出清结果已知 |
| 容量结果公布 | 实际中标和价格 | 更新可交易余量 | 已中标容量，不能在后续场景中撤销 |
| 每场日内拍卖 | 已公布的日前/容量/较早日内结果、新预测 | 对交付合同买卖增量 | 各早期交易按原价保存，不按最新价重估现金流 |
| 连续日内交易事件 | 当时可见订单簿及可成交深度、限额 | 有限深度内买卖增量 | 已成交逐笔头寸；关门后交易量为零 |
| aFRR能量开放 offer_open | D-1 12:00起开放，使用当时已发布信息 | 建立可提交报价接口 | 开放不等于容量结果已公布 |
| aFRR首版支持 initial_support_offer | D-1 20:00前；以已实际公布的容量结果、剩余状态和激活预测为基础 | 提交等于中标容量的首版支持报价 | 容量结果必须在该支持决策前已知 |
| aFRR更新 update_gate/last_update | 首版后按适用版本持续更新，交付前25分钟为既有研究所载更新接口 | 在更新许可内保持能量支持与能力一致 | 超过适用更新截止即固定 |
| 实时激活 | 已收到的指令、SOC、故障状态 | 跟踪外生激活并更新 SOC | 不能选择只执行有利激活；不能回改过去交易 |
| 次轮滚动优化 | 新测量值、已发布市场信息 | 尚未关闭的交易与后续容量 | 历史交易、已经履约的状态和即将交付的承诺 |

事件表至少包含 `event_id / offer_gate / result_release / delivery_start / delivery_end / timezone / rule_version / source_id`。未来公布的出清价可以作为预测场景随机变量，不能作为报价时已知输入。报价决策和成交结果必须处于不同信息节点；所有决策按共同历史实行非预知约束。

能量事件依据 `balancing_energy_rules.md` ES03-aFRR-002（P.O.7.2 Annex I §2.2及P.O.3.1 §13.3），具体日期仍按有效版本及官方时区转换。容量采购与日前结果的精确先后未闭合时，数值运行必须拒绝缺失时序，或使用明示的A05时序情景；不能静默假设。支持报价节点若位于容量结果发布之前，事件表校验报错。

连续日内事件另需 `market_status / suspension_scope / local_trade_allowed / cross_border_trade_allowed`：只在对应交易范围为TRADE且许可有效时交易，UPC/INT/FIN禁止交易。IDA收单前20分钟的相关跨区暂停与同区本地交易许可分别处理（`intraday_market_rules.md` §§3.1、4.2；Rules 44及Annex 2）。跨区暂停不自动关闭允许的本地交易。

## 3. 分市场策略

### 3.1 日前：确定基础电能头寸

买卖量表示合同平均 MW，结算按合同小时数换算 MWh。2025 年日前小时与 15 分钟产品按历史版本区分；小时合同在同一小时内的四个物理季度时段共享一笔成交量，不能拆成四次独立日前选择。

首版只表达简单可分订单，采用外生价格和外生接受比例，不模拟全欧洲出清。实际价格影响力、复杂块报价及策略性改价均不属于首版。给定模型条件下的全额接受情景需单独标注。

### 3.2 日内拍卖：调整，不重复记收入

例如日前卖出 10 MWh，后来日内买回 4 MWh：现金流保留日前卖出收入和日内买回支出，最终交付为净卖出 6 MWh。不能把 6 MWh 再按日内价格整体卖一次。

日内还承担恢复 SOC 和减少后续履约风险的作用。容量已中标后，每次调整后的基准计划都必须保留相应上下调空间；任何补能必须有未关闭市场的成交路径和实际充电过程。

### 3.3 连续日内：机会和执行限制一起进入

只有存在带时间戳的可成交价格、深度和合同开放状态时，才允许非零连续交易决策。首版采用吃单简化：买入用可见卖价，卖出用可见买价，数量不超过相应可用深度。没有此类数据时设置交易许可为零，或建立明确标注的合成流动性情景；汇总均价只可作参考。

连续市场中的不同时间成交允许反向交易；本模型按A10简化，在单一事件、单一合同不同时买卖，该互斥不是市场规则。输出保留逐笔成交、净头寸和现金流复算。不模拟排队优先级、挂单成交概率或市场冲击；若这些因素重要须扩展执行模型。

### 3.4 aFRR：功率空间与能量保障同时检查

容量报价是承诺；能源支持报价是后续义务；指令激活才改变实际电能。首版上下调分别决定，使用已验证资格限额或假定资格情景。自有站经聚合商参与时，供应商整体资格与本站分配限额分开。

能量报价量首版等于已中标容量，不提供额外未获容量报酬的能量报价。这是数量简化策略，不是规则禁止额外报价，也不代表已经完整重演持续更新与全部可用备用申报义务。报价价格作为外生策略参数，激活情景须与该价格、市场状态、接受比例的假设一致；本模型不优化能量报价价格。

必须检查连续上调、连续下调、无激活及交替激活路径。不能只用平均激活率，也不能把季度小时内上下调净额为零视作 SOC 安全。压力情景规定的持续时间属于假设，不能将15分钟产品长度称为法定持续供能要求。

## 4. 模型模式与允许结论

| 模式 | 信息与成交条件 | 允许结论 |
|---|---|---|
| 事后完美信息 | 对完整价格、接受比例、激活轨迹知情；其余约束与对照模型一致 | 同一假设集下的理论上限；不能称为可执行收益 |
| 多阶段情景/滚动 | 报价只依赖当时信息，后续决策按场景树分支 | 条件性策略比较；预测与执行数据验收后才可做预测回测 |
| 已实现结算重演 | 成交、激活、计量均为固定输入 | 校验现金流和偏差；不优化历史成交 |

## 5. 建模假设台账（A）

每项参数均须携带假设 ID、单位、来源/版本和敏感性范围。下表的“待填”不以零或随意经验值替代；符号模型可先审核，缺少必填参数时数值运行应报错。

| ID | 假设/设计选择 | 首版取值或处理 | 敏感性及替换条件 |
|---|---|---|---|
| A01 | 价格接受者 | 价格不随本站数量变化；交易量上限外生 | 增加规模上限与市场深度敏感性；大规模影响需新模型 |
| A02 | 资产与接网 | 单站或等效储能；MW/MWh/效率/限值待填 | 容量、倍率、接网方向限额由设备/接网资料替换 |
| A03 | SOC、初末状态 | 工作上下界与初始值待填；经济场景共同期末目标待填，压力场景使用显式安全终端区间 | 多天滚动与终端目标敏感性；无补能压力路径不强制回到同一目标；恢复需求单独披露 |
| A04 | 双向资格 | 方向资格开关及可报上限外生；未确认则只属假设场景 | 项目/聚合商回执替换；供应商100 MW门槛不强加单站 |
| A05 | 拍卖成交 | 事前报价量乘外生接受比例，价格外生；首版保守要求供应商容量中标为整数MW以匹配vP=RP | 该中标网格为建模限制而非官方中标必为整数；非整数已中标输入拒绝直接运行 |
| A06 | 申报简化 | 简单可分订单；供应商容量/能量报价每方向一段、1MW网格；本站合同份额可非整数 | direct_bsp与allocated_site_share必须分开；不启用25段及不可分报价优化 |
| A07 | 能量支持 | 首版仅允许报价量等于中标容量且不超过资格/接口限额，价格策略固定 | 数量简化不构成全部可用备用申报合规；扩展须增加更新节点与接受/激活模型 |
| A08 | 激活轨迹 | 外生逐细步正/负方向比例；与成交场景联合生成 | 不能从系统总量直接复制为本站；概率/分布待校准 |
| A09 | 能量保障 | 有限压力情景集：无激活、持续双方向、交替路径；显式关闭现货及未来新容量申报许可 | 保留既有/待出清义务和支持报价，覆盖承诺窗口；压力终端安全区间不代表已恢复或零恢复成本 |
| A10 | 连续日内成交 | 有可见价差、深度、时间戳时吃单；否则关闭 | 合成深度须独立标注；不能把汇总价当实际可成交价 |
| A11 | 基准与时间网格 | 首版季度内平坦电能计划，物理子步模拟激活 | 不等同于真实 PTR 斜坡；真实跟踪回测需独立 PTR 重建 |
| A12 | 效率与退化 | 固定充/放效率，交流侧吞吐量线性退化成本 | 非线性效率、温度、衰减可改分段线性；成本单位待填 |
| A13 | 偏差 | 主优化理想跟踪，残余偏差为零；误差只在外部审计输入 | 不允许主动选择偏差获利；真实误差/处罚模块须另验收 |
| A14 | 费用与聚合 | 买卖手续费、容量MW费用、激活MWh费用及固定费用外生 | 不默认免费；缺合同用多个明确费用情景 |
| A15 | 物理动态 | 子步内功率恒定、边界可切换；响应能力通过独立技术筛查 | 不能证明5分钟FAT或秒级跟踪达标；需要细化动态模型才能称合规 |
| A16 | 风险偏好 | 期望净收益，可选 CVaR；风险参数待填或显式关闭 | 比较风险中性与风险厌恶，不将结果称保证收益 |
| A17 | 聚合结算归属 | direct_bsp时w=1；allocated_site_share时供应商有效报价/中标乘事前固定w，本站份额可非整数 | 合同需允许对应报价块决策，其他资源承担余下份额属外部假设；实际BSP/BRP合同和计量边界替换 |
| A18 | 故障/技术约束 | 首版选取无额外再调度的研究场景；已知停机用限值覆盖 | 真实样本有未建模调度时排除/扩展，不静默忽略 |

## 6. 规则事实（F）与未决事项（U）

规则来源继承既有审核：aFRR 容量上下方向、15分钟、报价粒度及支持义务见 `S-CNMC-2024-MP` 与 `S-CNMC-2024-11535-PO`；日前/日内合同、增量成交、结算与时序见 `S-SP-BOE-2025-RULES`；偏差调整见 `S-CNMC-2025-QH` 及历史 P.O.14.4 版本。完整元数据在 `countries/ES/sources.md`，数学规格另给直接链接和定位。

项目资格、持续能量要求、实际PTR重建、结算分配、连续市场执行数据、正式收益字段单位与研究期逐日版本仍待输入阶段验收。它们不在此被改为事实；缺少证据的模块只可输出带假设标记的结果。所有数值结果必须附“使用了哪些 A、未覆盖哪些 U”。

## 7. 策略验收标准

1. 同一物理电池承担所有市场义务，容量占用功率/能量，补能支付现货成本。
2. 已成交历史锁定，未来信息不回流；连续交易无数据时关闭。
3. 容量报价、中标、能量支持和激活分离；上下调均有能量路径。
4. 明确理论上限、情景优化、结算重演三类结果；假设和未决项可追溯。
5. 策略通过独立审核后，数学规格方可标记批准。
