# 联合核心：独立手算验收锚点

仅用于人工构造的合成数据；不是西班牙真实价格或收益。基线为draft-4，充放电效率各0.92，现金单位EUR。

## 现金与单位

1. 同一15分钟，DA售10 MW、价格50 EUR/MWh，IDA购4 MW、价格30 EUR/MWh：最终基线6 MW；DA现金125，IDA现金-30，合计95。不能按最终6 MW重复结算两个市场。该检查仅测现金算术，不单独宣称10 MWh初始电量可支撑该放电。
2. 同一小时售10 MW、价格50 EUR/MWh：交付10 MWh、现金500。四个QH各映射10 MW，只能有一个合同决策，不是4个独立变量。
3. 15分钟容量20 MW，原价8 EUR/MW/hour：标准化价格2 EUR/MW/period，现金40。若输入已经是2 EUR/MW/period，不得再次乘0.25。
4. 上调容量20 MW、强度0.2、现金系数100 EUR/MWh：激活电量1 MWh、现金100。下调容量20 MW、强度0.4、现金系数-30 EUR/MWh：激活电量2 MWh、现金-60。上下调合计激活现金40，不自动把下调负系数改成正收入。

## 物理路径

1. 基线10 MW，上调20 MW、下调30 MW，强度0.2/0.4：实际功率30/-20/10 MW，持续3/6/6分钟。AC放电2.5 MWh、充电2 MWh；DC净减少0.877391304348 MWh，双向吞吐4.557391304348 MWh。下调段必须按实际充电效率计算。
2. 基线0，上下调容量各20 MW，强度0.2/0.4，起点11 MWh：U顺序先放1 MWh AC，SOC降至9.913043478261，再充2 MWh AC；QH末为11.753043478261。虽末端回到区间，内部仍违反10 MWh下界。D顺序同末端但路径不同。
3. 基线90 MW、上调容量20 MW，即使上调强度为0，110 MW备用头寸也应判不可行。
4. AC充电180/0.92 MWh，再AC放电180×0.92 MWh：DC双向吞吐360 MWh，恰为1 EFC。不能用AC吞吐直接除360。

第1/2项物理锚点是隔离物理组件检查，不替代整个独立连续区间首尾10 MWh的正式合成优化边界。
