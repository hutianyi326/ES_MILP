# 西班牙完美信息回测：aFRR数据门禁复核

核查日期：2026-09-20（Asia/Shanghai）  
范围：首版事后完美信息回测使用的 aFRR 680/681 激活能量、632/633 上下调备用分配，以及它们形成系统平均激活强度代理的最低数据条件。  
目标回测范围：Europe/Madrid 本地时间 `2025-01-01 00:00`（含）至 `2026-09-01 00:00`（不含），对应 UTC `2024-12-31 23:00Z`（含）至 `2026-08-31 22:00Z`（不含）。  
本报告不修改模型、不生成处理后数据、不覆盖既有 `data/raw/ES/` 文件。

## 1. 结论先行

当前可以放行的是**数据解析和候选映射诊断**，还不能放行真实历史 MILP 回测。原因不是 90/180 天场景校准，也不是 `step_type=step` 的前填语义；本阶段已经采用完美信息模式，只使用 API 明确返回的记录，不对缺口前填、拆分或补零。Europe/Madrid 是计算窗口、自然日/年度归属、7天滚动窗口和循环预算归属的主时区，不只是展示时区。

真正仍阻断历史激活收益和 SOC 路径进入生产回测的最小问题有四组：

1. **680/681 的公开 API 指标尚未被官方直接交叉到 ESECS/ESECB 或其他明确的 MWh 结算字段。**官方规则能够确认 aFRR 结算能量的量纲为 MWh，但 API 返回的 `magnitud` 只有 `Energía`，没有 `MWh`/`kWh` 字符串，也没有公开的指标 ID 交叉表。不能仅凭指标名称或数值大小猜测单位。
2. **总体可比性尚未闭合。**尚未确认 680/681 是否包含同一 QH 内没有对应 632/633 容量中标的参与者、跨境/PICASSO成分或其他系统聚合成分，因此不能把候选比值解释为备用容量的履约比例。
3. **API 时间戳区间语义尚未闭合。**`datetime_utc` 的值代表QH起点还是终点、边界能量如何归属尚未由官方字段说明确认；这与 `step_type` 的前值保持语义是两个独立问题。
4. **正式可执行掩码尚未生成。**已有原始记录可以计算四指标的显式交集和候选连续区间，但在上述指标口径、价格序列和市场制度边界最终核验前，本报告不把这些候选区间称为“已验收区间”。可复算的候选审计结果保存在同目录 JSON 中，不等于生产输入。

相反，以下事项不再阻断首版完美信息模式：

- 不需要 90/180 天预测校准窗口或场景权重；激活比例由历史显式记录直接形成事后已知参数。
- 不需要使用 `step_type=step` 做 forward-fill；没有记录的 QH 直接作为缺失，切断连续区间。
- 不要求当时已经发布最终价格版本。完美信息模式可以使用事后最终价格，但必须保留价格原始版本、获取时间、修订状态和 `perfect_information_override=true`，把“决策时可得信息”与“事后最终结算输入”分开记录。
- 系统聚合量映射到本站是已确认的建模假设，不是本站实测调用，也不要求公开系统量等于本站量；该假设必须在回测结果中单独标记。但它不能替代 680/681 的单位和总体可比性证据，也不能授权主线程猜测单位。

## 2. 官方规则和接口事实

### 2.1 aFRR 规则层面的能量单位和时间结构

REE/CNMC 的 P.O.7.2（BOE-A-2024-11535）明确：

- aFRR 能量报价按每个调度四分之一小时（QH）组织；报价功率单位为 MW，能量价格单位为 EUR/MWh。
- aFRR 实际控制在 4 秒周期执行，一个 QH 包含 225 个控制周期。
- 上调、下调分别计算 `ESECS`、`ESECB` 等结算能量变量，并在 QH 汇总。
- 因此官方结算公式的量纲为 `MW × s / 3600 = MWh`。

这些事实确认了**规则结算能量**的 MWh 量纲，但没有自动证明公开 eSIOS 指标 680/681 就是该结算变量的逐条公开序列。

官方来源：

- CNMC/BOE，Resolución de 25 de abril de 2024，P.O.7.2，发布 2024-06-06，官方 PDF：<https://www.ree.es/sites/default/files/2024-11/PO_7_2_BOE-A-2024-11535.pdf>。重点为 PDF pp.6–7 的报价和激活结构、实体第12–13页（BOE印刷页66388–66389）的 `ESECS/ESECB`、4秒/225周期及 QH 计算、Annex III 的测量和结算规则。
- REE，Guía de implantación del Servicio de Regulación Secundaria，2024-10 版本：<https://api.esios.ree.es/documents/2399/download?locale=es>。重点为已核证实体 PDF 第53页（印刷页49）的4秒计算、225周期/QH和 `ESECS/ESECB` 能量结算公式。该指南属于 2024 年西班牙本地 Phase I，不能直接外推 PICASSO 接入后的全部历史口径。
- REE，Servicios de ajuste del sistema，持续维护页面：<https://www.ree.es/es/operacion/garantia-suministro/servicios-ajuste>。页面说明二次调节能量对应 aFRR 的使用，并按可用性和净使用量结算。

## 3. 632/633 与 680/681 的可比性

### 3.1 允许进行的候选诊断

在以下前提全部满足时，可以把系统平均激活强度作为候选诊断量：

```text
alpha_up_q   = E680_q / (R632_q × 0.25 h)
alpha_down_q = E681_q / (R633_q × 0.25 h)
```

其中：

- `R632`、`R633` 是同一 QH 的上、下备用分配功率；
- `E680`、`E681` 必须已经被官方或登记的项目数据合同确认是同一 QH 的 MWh 激活能量；
- 结果是**系统层面的方向性激活强度代理**，不是本站实际激活率；
- 不能把 632/633 当成激活量，也不能把 680/681 当成本站调用量。

因此，632/633 与 680/681 在方向上可配对、在时间索引上可对齐；但在 680/681 的单位和公开结算字段映射闭合前，物理量可比性只能标记为 `conditional`，不能写成已确认的 MWh/MW 比值。

## 4. 连续区间：当前只能登记候选，不能称为已验收

定义候选区间的技术条件为：

1. 632、633、680、681 四个指标均有显式记录；
2. 相邻 UTC 时间戳严格相差15分钟；
3. 四个值均有限、没有冲突副本，632/633 分母非零；
4. 不使用 `step_type=step` 前填，不用小时值拆分 QH；
5. `alpha_up >= 0`、`alpha_down >= 0` 且两者之和不大于1；
6. 因一个缺失点或不可映射点而切断。

**不存在“至少7天”这一数据验收门槛。**7天只是滚动优化的标准窗口；末尾不足7天可以按已确认口径缩短窗口，任何长度的合格连续段都应保留为候选并在 JSON 中记录其起止时间。

按 Europe/Madrid 目标窗口、UTC 主键和上述条件，只读审计得到 **129 段候选连续区间**，其中 22 段至少达到672个QH。最长候选段为 `2024-12-31 23:00Z` 至 `2025-03-30 00:45Z`（右开，8,455个QH）；完整的129段（含短段）见：

`countries/ES/audit_pi_candidate_20260920_evidence.json` 的 `candidate_continuous_runs.runs`。

这些区间只是便于主线程设计正式掩码的审计结果；脚本是**候选审计器，不是生产数据验收器**。由于 680/681 的 API 单位/字段交叉、总体可比性、时间戳起止语义和日前/日内/aFRR价格联合覆盖尚未闭合，**当前不批准直接把任何候选区间送入历史 MILP**。

### 市场状态与缺失的区分

后续把价格或成交输入与候选区间合并时，必须先读取市场状态：

- 有官方证据确认的取消场次标记为 `cancelled_not_tradable`，表示该场次不可交易；它不应被误报为“价格缺失”，也不应仅因没有价格值就按普通数据缺口解释。
- 空文件、HTTP 404、传输错误或空值原因未知/未分类时，标记为 `unknown_missing`，排除出联合输入掩码并切断连续区间。
- 取消场次仍需在结果中披露，不得自动填零、复制邻点或将取消视为零价交易。

## 6. 分层判断

### 规则事实

- P.O.7.2 和 REE SRS 指南规定 aFRR 以 QH 组织、4秒控制并将方向性激活能量汇总结算；规则量纲路径支持 MWh。
- eSIOS API 公开 632/633 为上、下备用分配功率指标，680/681 为上、下激活能量名称，地理范围为 Península；API原始字段仍只直接给出 `Potencia`/`Energía` 等标签。

### 研究解释

- 680/681 与 632/633 在方向和 QH 索引上具备形成 `E/(R×0.25h)` 候选比值的结构，但该比值只有在 680/681 的单位和字段映射闭合后才可用于正式模型。
- 四个 `alpha_sum > 1` 样本更适合被视为当前映射不可用点，而不是被强行解释为系统激活超过承诺容量。

### 建模假设

- 系统平均激活强度映射到本站；这是假设，不是 REE 对本站的分配规则。
- 完美信息优化器可以读取事后最终价格版本；这是假设性回测口径，不代表实时可执行策略。
- 每个连续区间独立处理，缺口不传递 SOC；区间初末 10MWh 等其他边界按主线程已确认规格执行。

## 7. 仍未决及责任边界

1. 最小实质未决：680/681 的 API 指标单位及其与 ESECS/ESECB 的公开交叉映射；没有证据就维持门禁关闭。
2. 总体可比性未决：680/681 是否含 QH 内没有对应 632/633 容量中标的参与者、跨境/PICASSO激活或其他系统聚合成分，以及是否能作为 632/633 的同口径分子。
3. 时间语义未决：API `datetime_utc` 是所代表QH的起点还是终点，边界/更新值如何定义；这与 `step_type` 的保持/插值语义是两个独立问题。
4. 最小工程未决：正式掩码和全市场输入（价格、容量、激活能量）的联合时间交集；确认取消场次与未知空值必须分别编码。
5. `step_type=step` 的官方保持/插值定义仍未找到，但在本方案“不前填”的模式下，它不是单独的历史回测阻断；如果将来要做稀疏序列扩展，必须另行取得证据并登记假设。
6. 不把 2024 年7–11月小时/混合粒度样本直接并入首版 QH 回测；2024资料可作口径比较，不作为当前正式样本。
