## 研究问题

只核验公开官方数据接口和数据使用边界，不下载项目数据、不执行回测：

1. OMIE/REE/ENTSO-E/ACER 公开页面、文件和 API 的指标、字段、单位、时间戳、市场日/交付日定义；
2. 西班牙本地时间、CET/CEST、夏令时 23/25 小时日与 15 分钟/小时/日结算轮次的转换；
3. 2025 历史覆盖范围、缺失值、文件更正/修订标志、版本号和发布时间；
4. 公开数据与 REE/OMIE 受限参与者文件的权限边界、保留期和项目级可见性；
5. 哪些字段可用于规则核验，哪些必须从项目/BRP/BSP/计量责任方取得；
6. 2026-08-11 后的接口或 96 轮变更如何标记为未来/当前，不回填 2025。

## 来源要求

优先使用 OMIE、REE、CNMC/BOE、ENTSO-E、ACER 的官方 API 文档、公共文件格式、数据目录、结算/计量指南、版本公告和时区/日历说明。每项关键 claim 必须记录机构、标题、发布日期或生效关系、URL、访问日期、条款/页码/API 定位，并在 `countries/ES/sources.md` 建立唯一 `S-*` source ID。
