## 报告结构

每个运行情景生成一份独立报告，章节顺序固定。报告开头注明电站功率、能量配置、正式统计区间、中标模式和运行状态。

| 章节 | 默认内容 | 主要回答的问题 |
|---|---|---|
| 假设概览 | 数据来源、正式期与观察期、时区和分辨率、原始字段完整度、结算覆盖率、空闲桥接和阻断情况、电池配置、效率、EFC预算、关键假设 | 本次测算基于什么条件，数据覆盖多少？ |
| 结果概览 | 全期／月均／自然年收益；最新滚动12个月收益；逐月滚动收益图表；全期／月均／自然年EFC；六市场收益及占比；平均执行功率和申报容量 | 收益规模、收益构成及电池使用情况如何？ |
| 月度结果概览 | kEUR与kEUR/MW两张月度图、对应两套金额明细、每年月均和合计 | 哪些月份收益高，由哪些市场贡献？ |
| 小时级结果概览 | 全期0–23时收益图、月份×小时热力图、Q1–Q4小时图 | 收益集中在哪些时段，如何随月份和季节变化？ |
| 输出文件与口径 | 配套CSV、图表、输入来源与统计方法定位 | 如何查看明细、核对和复算？ |

沿用六市场顺序：DA电能、ID电能、aFRR容量上调、aFRR容量下调、aFRR激活上调、aFRR激活下调。上下方向始终单列。

建议新增两项：假设概览列累计求解器时间和总运行时间（若归档未提供则显示“未记录”）；月度金额明细后增加六市场月度占比表，回应此前关于月度市场贡献比例的展示要求。

## 指标和聚合口径

| 项目 | 默认开发口径 | 状态 |
|---|---|---|
| 正式时间范围 | 所有收益和EFC按正式执行范围聚合，观察日收益及末端估值不进入正式现金收益。页面日期显示包含最后交付日；内部区间仍使用右端不含，不能在同一句中混淆两者 | 沿用并修正日期文案 |
| 时区与夏令时 | 按Europe/Madrid展示；用UTC唯一识别QH；当地日按实际92／96／100个QH检查；重复小时按UTC偏移分开计样本 | 沿用 |
| 收益名称 | 统一使用“市场现金收益”；收益是六市场带符号现金流之和。说明尚未扣除模型未计入的项目投资、运维等成本 | 建议修正文案 |
| 单位 | kEUR＝EUR÷1000；kEUR/MW＝EUR÷1000÷本次额定放电功率MW。两小时和四小时均按MW归一化 | 沿用 |
| 精度 | 金额表和收益CSV保留两位小数；计算使用未舍入值，展示时才舍入；显示层将负零规范为0.00 | 沿用并补齐负零处理 |
| 全期及月度收益 | 累计有效结算QH的现金流，负值保留；不按缺失比例外推。整月无有效现金记录时显示空值及覆盖率，不展示成真实零收益 | 沿用并补齐全缺失边界 |
| 月均 | 完整有效月份范围内，默认沿用总收益÷统计月份数的算术月均；若有部分自然月或全缺失月份，列明纳入月数及覆盖，不能称为完整月均。全缺失月份不按0纳入有效月均 | 建议补齐适用范围 |
| 自然年统计 | 按年份汇总实际测算范围，年末列年度月均和年度合计；2026年1–8月合计明确标注“2026年1–8月” | 沿用并补齐范围标签 |
| 完整天 | 当日所有预期QH均有效才计完整天。建议同时列“完整有效天／统计期天数”和“统计期天数／全年天数”，例如190/243和243/365；不能将完整天筛选误用于删掉部分有效日的收益 | 建议补齐覆盖解释 |
| 滚动12个月 | 统计月及此前11个连续自然月的收益合计。要求正式范围覆盖这12个自然月，每月至少有有效结算记录；QH缺失仍保留覆盖说明。不以不足12个月的结果乘倍数替代 | 沿用并补齐部分月及缺月边界 |
| 最新滚动年收益 | 使用最新一个可形成上述窗口的月份，同时显示起止月和窗口QH覆盖率；“12个月”表示日历跨度完整，不代表每个QH完整 | 建议修正文案和覆盖披露 |
| EFC | 汇总模型输出的已执行EFC，注明模型的可用能量分母。不得仅按QH起末SOC净差重算，避免漏掉同一QH内不同激活相位的充放电吞吐；完整充放电事件次数不与EFC混用 | 沿用模型记录并明确解释 |
| 市场占比 | 某市场带符号现金收益÷同范围六市场总收益；负占比保留，总收益为0时显示“不可定义”。仅正收益部分占比之和可能超过100% | 沿用并补齐零分母 |
| 小时收益 | 四个QH全部有效才形成一个样本小时；先合计该小时四个QH收益，再按同一当地钟点的有效小时样本求均值。不同钟点各用自己的样本数 | 沿用 |
| 季度小时收益 | 按跨年份同一季度合并小时样本，Q1至Q4各一张图，并列明纳入的年份／月份及样本数 | 沿用并补齐样本范围 |

月度收益利用所有有效QH，小时图只利用完整有效小时，两者样本集合不同。小时均值图用于观察时段特征，不能直接将24个均值相加作为全期总收益。

## 平均功率和中标模式

平均功率的分母沿用全期正式QH数，空闲桥接按0计；存在未知状态阻断时须披露覆盖限制，不能把未知执行功率解释为真实0。

| 展示行 | 计算与解释 |
|---|---|
| DA执行功率 | 逐QH对DA交易买卖净额求有符号MW，再求均值；卖电为正、买电为负 |
| ID执行功率 | 同一交付QH内所有ID交易买卖净额汇总后求有符号MW均值 |
| DA＋ID合并现货执行功率 | 逐QH合并DA与ID后求均值，用于观察现货合并净头寸 |
| aFRR上／下容量 | 分方向展示模型计划申报／预留MW的均值，中标系数不缩减该表中的MW |
| aFRR上／下激活 | 分方向将执行MWh按时长换算MW后求均值，方向由行名标识 |

报告注明：DA／ID方向均值会发生买卖抵消，不能据此单独判断交易活跃度；各行不可相加视为电站容量分配比例。

模式说明必须由实际运行元数据生成：

| 模式 | 报告必须说明 |
|---|---|
| `full_fill` | aFRR容量按100%中标计价；本情景未使用容量收入折减系数 |
| `optimize` | 历史逐QH、逐方向系统分配容量／总报价量的代理系数进入容量收入目标后重新优化；激活收益和完整备用的物理约束沿用模型定义 |
| `posthoc` | 先按100%口径优化，再折减容量现金；决策沿用原解，不能写成按中标系数重新优化 |

系数明确标注为建模敏感性代理；GCT余量检查保留“第一阶段全额成交条件下的建模假设”标识。完美信息结果标为事后条件收益，不将两日滚动结果宣称为已证明的全时域全局收益上界。市场规则和系数方法继续引用已有研究文档。

## 图表规范

每份单场景报告默认包含9张SVG，图后提供对应数值表或CSV定位。

| 图表 | 数量 | 横轴和纵轴 | 展示重点 |
|---|---:|---|---|
| 滚动12个月收益折线图 | 1 | 横轴统计月YYYY/MM；纵轴kEUR/MW | 长期收益水平的变化；不足12个月显示原因 |
| 月度收益堆叠柱状图 | 2 | 横轴YYYY/MM；纵轴分别kEUR、kEUR/MW | 六市场贡献，正负收益分别堆叠；下方提供两套金额表和月度占比表 |
| 全期小时堆叠柱状图 | 1 | 横轴0–23；纵轴小时平均收益 | 六市场的典型日内收益分布 |
| 月份与小时热力图 | 1 | 横轴0–23；纵轴YYYY/MM；格值kEUR/MW | 当月该钟点的平均总收益；零中心色标，蓝正红负，缺样本为灰色／破折号 |
| 季度小时堆叠柱状图 | 4 | Q1至Q4各一张；横轴0–23 | 季节差异；建议同一报告内四季度共用纵轴范围 |

柱状图纵轴统一10个等距区间、11个刻度，刻度采用整数及清晰的5／10倍数步长。小时图用“kEUR/MW × 10⁻³”缩放，使小额收益可读，例如刻度30代表0.03 kEUR/MW；表格和热力图仍明确实际单位。六市场颜色、顺序和图例在所有报告中一致，沿用当前配色。

仅在提供兼容的100%中标基线数据时，滚动图叠加第二条线并列差额。必须核对功率、能量配置、窗口、统计区间及主要假设；四小时报告默认对照四小时100%口径。没有比较数据时只画当前曲线，并删去“两条线”等文字。两个独立优化情景的收益差须说明包含调度变化。

两小时／四小时和不同模式可另生成对比报告：总览表、月度表、小时表均列两情景及差额，并链接各自完整报告。差额统一标注计算方向，场景名称包含电站时长和中标模式。

## 数据接口和开发步骤

输入沿用现有运行目录中的`manifest.json`、`summary.json`、`result.json`、`solver_input.json`和`cash_ledger.json`；从元数据读取参数，不以文件夹名称推断电池规模。来源文件或关键参数缺失时显示缺失情况；无法确认归一化分母时不生成每MW收益。

开发主要落在`code/project/build_es_result_presentation.py`和`code/tests/test_es_result_presentation.py`，完成后更新README使用说明。步骤如下：

1. 统一指标定义、日期边界、零／空值和覆盖率规则，补齐模式与基线元数据判断。
2. 按固定章节生成报告，落实场景文案、月度占比、用时、覆盖说明和图表尺度。
3. 用现有两小时含系数、四小时100%、四小时含系数结果生成新目录，保留旧报告。
4. 执行下列验收，提交真实样例和测试记录供确认。报告开发不需要重新求解MILP。

交付包括：结果展示MD、9张SVG、月度／年度／小时／季度／热力图／滚动12个月CSV；建议新增月度市场占比CSV。保留来源路径、系数哈希、报告版本及覆盖信息。

## 验收标准

| 验收项 | 测试输入 | 预期行为与证据 |
|---|---|---|
| 金额一致 | 含正负收益的六市场QH样例及已有真实运行 | 图表与CSV来自同一未舍入聚合；分项合计与总额一致；显示两位小数，舍入差可解释 |
| 日期边界 | 带观察日的运行、部分首末月 | 正式现金排除观察日；显示日期不误减一天；部分月标注，不能凑出完整滚动年 |
| 覆盖率 | 缺QH、整月缺失、零收益但数据有效、闰年 | 缺失和真实0可区分；完整天及全年天数分母正确；无效滚动窗口不显示为0收益 |
| 夏令时和小时过滤 | 92／100 QH日及某小时缺1个QH | 日长正确、重复小时分开计数；不完整小时排除且样本数可核对 |
| 三模式文案 | full_fill、optimize、posthoc元数据 | 标题、假设、系数来源和决策说明与模式匹配；无系数时不写折减已启用 |
| 比较基线 | 无基线、兼容基线、两小时与四小时混配基线 | 无基线只显示一条线；兼容基线同窗口比较；混配明确拒绝作为同配置中标敏感性对照 |
| 平均功率 | 同QH多笔相反现货交易、激活MWh、空闲桥接 | DA／ID净额与合并值正确；激活按时长换算；分母明确，中标系数不缩减申报MW |
| 视觉和比例 | 负月收益、小额小时收益、总收益为0 | 负柱可见、10等距区间、小时缩放标明；占比零分母显示不可定义；热力图缺样本不冒充0 |
| 真实样例 | 当前两小时及四小时三份单场景结果 | 新报告链接有效、SVG可显示、金额可与原始现金核对，核心指标与已有结果的差异逐项解释 |
