# ES-06：西班牙官方数据目录与历史版本整合

## 1. 任务状态

- 主线程状态：已完成并通过 ES-G6 第二轮独立复审（2026-08-18，P0/P1/P2=0）
- 前置门禁：ES-G5 已通过，P0/P1/P2=0
- 研究基线：2025-01-01—2025-12-31 历史期；规则基准日 2026-08-11
- 研究对象：西班牙辅助服务、平衡能量和不平衡结算官方数据接口
- 责任 Agent：`market_researcher`
- `modeling_engineer`：继续禁用

## 2. 研究目标

建立可复核的西班牙官方数据目录和版本时间线，明确每个数据集的提供方、URL、字段、时间分辨率、时区、单位、币种、发布延迟、修订机制、历史覆盖和访问限制。将 2025 历史规则与 2026-08-11 基准版本分开，不把尚未核验的 API 字段或下载覆盖写成事实。

## 3. 必须研究的内容

1. REE/eSIOS 平衡容量、aFRR、mFRR、RR、IN/IGCC、调频激活和不平衡价格数据入口；
2. BRP 偏差、MEDBC、POSFIN/PHFC、AJUDSV、DESV、PDESV/PDESVS/PDESVB 等结算字段；
3. 储能双向计量、active entrante/saliente、QH 最佳能源和表计/遥测来源字段；
4. 欧洲平台数据（PICASSO、MARI、TERRE、IGCC）与西班牙本地数据的映射；
5. 2025 年 15 分钟 ISP、P.O.14.4 版本切换、MARI/PICASSO 接入、TERRE 2025-12-30 停止等时间边界；
6. 数据发布时滞、初始/最终闭算、revision/republication、缺失值和更正窗口；
7. 历史下载可得性、访问权限、API 限制、字段变更和可复现性风险；
8. 与 ES-04/ES-05 对照：SOC、持续时长、补能、FCR/SRAD 资格、2026 RR 替代仍保持未决，不得从数据字段反推规则约束。

## 4. 明确排除

- 日前、日内和 OMIE 现货市场数据与完整规则；
- 交易策略、MILP、国家配置、生产代码、历史回测和预测模拟；
- 未经授权下载或保存大批量原始时序文件；本任务只交付数据目录和版本元数据。

## 5. 证据要求

每个数据集和关键字段必须记录：source/data ID、提供机构、页面或文件标题、发布日期/生效关系、URL、访问日期、字段/表格/章节定位、历史覆盖、时区、分辨率、单位、币种、发布/修订说明和证据状态。优先使用 REE/eSIOS、BOE/CNMC、MITECO、ENTSO-E、ACER 等第一方资料。

必须区分规则事实、数据接口事实、研究解释和建模假设。无法验证的 API 字段、历史覆盖、延迟或权限必须标为 `open/provisional`，不得转成模型输入。

## 6. 交付文件

- `countries/ES/data_catalog_and_version_timeline.md`：官方数据目录、字段字典、版本时间线和可复现性风险；
- 更新 `countries/ES/sources.md`、`countries/ES/open_questions.md`、必要时更新 `countries/ES/product_scope.md`；
- 不修改 `model/`、`src/`、`tests/`、`outputs/`、`data/raw/`。

## 7. ES-G6 验收条件

- 主要官方数据入口和数据集逐项登记；
- 关键字段、时间分辨率、时区、单位、币种和版本边界有定位或明确标记为未决；
- 2025 历史期与 2026-08-11 基准日版本分开；
- 发布延迟、闭算、修订、缺失值和 API 可得性不被误写为确定规则；
- ES-04/ES-05 的未决事项保持一致；
- 未越界进入现货、策略、模型、代码、回测或未经授权的原始数据下载。

完成后提交主线程审查，再由独立 review agent 执行 ES-G6 复审。
